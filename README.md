# Basic_Verilog_ALU

Inspired by my computer architecture and organisation module, I decided to learn some verilog, getting to the stage where I had a more or less credible piece of work: an 8-bit ALU which can add, subtract and do other operations such as an AND evaluation or a right-shift

**Produced using Coddy Tech ide for verilog**:  https://coddy.tech/playground/verilog
